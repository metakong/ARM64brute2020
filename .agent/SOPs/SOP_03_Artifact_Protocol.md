# SOP_03_Artifact_Protocol

## Rule
All structural codebase changes must be output as a Markdown Artifact plan before execution.

## Implementation Details
- Prior to modifying directory structures, major logic blocks, or database schemas, generate an implementation plan artifact.
- The plan must detail the proposed changes, affected files, and potential risks.
- Wait for user acknowledgment or perform a sanity check against existing SOPs before proceeding with the execution.
