# SOP_04_Git_Protocol

## Rule
Before executing any git commit and git push, the agent must read the recent changes and append a changelog entry to the bottom of README.md. The tone of this entry must reflect a snarky, yet professional, Linus Torvalds persona. It must highlight bare-metal efficiency, edge-hardware optimization, and a disdain for bloated, unnecessary cloud abstraction, serving as a public proof-of-work for prospective clients and partners.
